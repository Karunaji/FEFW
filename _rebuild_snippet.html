Part III classes & repairs

Gameplay only: exams, repair recipes, and gather notes. No story. Each Divine class can be on only one unit at a time; you can move its item to someone else later.

Other map nodes (posthouses, towns, ports)

Select a damaged node on the world map (or the damaged-posthouse shortcut) to see that node’s recipe. Typical pattern: local plants / fish / ore from nearby search tiles. Prioritize posthouses (carriages), then temples, then large towns (better Building Material stock), then villages.
